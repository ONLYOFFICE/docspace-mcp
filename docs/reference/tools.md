# Tools

The ONLYOFFICE Apps MCP server implements the Tools concept from the MCP specification.

## Toolsets

A toolset is an ONLYOFFICE Apps MCP server extension to the standard MCP Tools concept.
Toolsets provide logical grouping of related tools to organize
ONLYOFFICE Apps functionality into manageable categories.

<!--generate toolsets-start-->

| #   | Toolset Name | Toolset Description                                                                                                                                                                                                                                                 |
| --- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | `ai_rooms`   | Operations for working with AI rooms: instructions rooms with skills, knowledge rooms with files for retrieval, and AI projects that link them, set the chat model and are shared with a team. Requires ONLYOFFICE Apps 4.1 or later with AI enabled on the portal. |
| 2   | `files`      | Operations for working with files.                                                                                                                                                                                                                                  |
| 3   | `folders`    | Operations for working with folders, including the 'Files' section (formerly 'My Documents').                                                                                                                                                                       |
| 4   | `people`     | Operations for working with users.                                                                                                                                                                                                                                  |
| 5   | `rooms`      | Operations for working with rooms.                                                                                                                                                                                                                                  |

<!--generate toolsets-end-->

## Regular tools

Regular tools are standard MCP Tools. Each tool corresponds to a specific
ONLYOFFICE Apps operation.

<!--generate tools-start-->

### AI rooms toolset

| #   | Tool Name                   | Tool Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| --- | --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | `create_ai_room`            | Create an AI room. An instructions room (10) holds skills: Markdown files uploaded with upload_file into the room itself, each starting with a YAML frontmatter between two --- lines with name (lowercase letters, digits and single hyphens, up to 64 characters) and description (up to 1024 characters); a room holds up to 100 skills. A knowledge room (11) holds files that are vectorized for retrieval, such as txt, md, docx, xlsx, pptx and pdf up to 30 MB: upload text with upload_file or copy documents into it with copy_batch_items; it can be created and filled only while vectorization is enabled. An AI project (12) holds no files: link instructions and knowledge rooms to it with link_ai_project_sources, choose its chat model with set_ai_project_model and invite the team with set_room_security. |
| 2   | `delete_ai_room`            | Delete an instructions room, a knowledge room or an AI project with all its files. The deletion is permanent: the room does not go to the trash, and AI rooms cannot be archived. Rooms of other types are refused.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| 3   | `get_ai_config`             | Get whether AI and vectorization are enabled on the portal. Call it before working with AI rooms: when aiReady is false, the other AI room tools are refused, and when vectorizationEnabled is false, knowledge rooms cannot be created or filled.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| 4   | `get_ai_profiles`           | Get the chat model profiles of the portal that an AI project can use.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| 5   | `get_ai_project_model`      | Get the chat model of an AI project. A missing or null profileId means that the project uses the default model of the portal.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| 6   | `get_ai_project_sources`    | Get the instructions and knowledge rooms linked to an AI project.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| 7   | `get_ai_rooms_folder`       | Get the AI rooms section with instructions rooms, knowledge rooms and AI projects. These rooms are not listed by get_rooms_folder.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| 8   | `get_ai_skills`             | Get the skills of an instructions room, or of all instructions rooms linked to an AI project. A skill ID is the ID of its Markdown file, which get_file_info and download_file_as_text accept.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| 9   | `link_ai_project_sources`   | Link instructions and knowledge rooms to an AI project. Every member of the project gets read access to the linked rooms. A project links up to 20 rooms of each type; rooms already linked are skipped. Linking needs the right to edit the project and each room.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| 10  | `retry_vectorization`       | Vectorize files of a knowledge room again, such as files whose vectorizationStatus is 2 (failed). Only room managers can do it, and only for files whose security.Vectorization is true. Files that are already vectorized or being vectorized are skipped without an error. Check the progress with the vectorizationStatus field of get_file_info.                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| 11  | `set_ai_project_model`      | Set the chat model of an AI project to a profile from get_ai_profiles. The model can be replaced but not reset to the default model of the portal.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| 12  | `unlink_ai_project_sources` | Unlink instructions and knowledge rooms from an AI project. The project members who are not members of a room lose access to it. Rooms that are not linked are ignored.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |

## Meta tools

Meta tools are an ONLYOFFICE Apps MCP server extension to the standard MCP Tools
concept. They provide a dynamic interface for tool discovery and execution,
allowing AI models to interact with tools without requiring all tools to be
loaded simultaneously.

When enabled, regular tools are wrapped into meta tools. Meta tools work in
conjunction with the same toolset and tool configuration options as regular
tools, providing the same level of control over available functionality.

<!--generate meta-tools-start-->

| #   | Meta Tool Name           | Meta Tool Description                                                                                                                                                                           |
| --- | ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | `call_tool`              | This is a meta tool for calling a tool. The list of available tools can be obtained using the list_tools meta tool. The input schema can be obtained using the get_tool_input_schema meta tool. |
| 2   | `get_tool_input_schema`  | This is a meta tool for getting an input schema for a specific tool. The list of available tools can be obtained using the list_tools meta tool.                                                |
| 3   | `get_tool_output_schema` | This is a meta tool for getting an output schema for a specific tool. The list of available tools can be obtained using the list_tools meta tool.                                               |
| 4   | `list_tools`             | This is a meta tool for listing available tools of a specific toolset. The list of available toolsets can be obtained using the list_toolsets meta tool.                                        |
| 5   | `list_toolsets`          | This is a meta tool for listing available toolsets. Toolset is a set of available tools.                                                                                                        |

<!--generate meta-tools-end-->


## Resolving tools

The tools resolution process follows a sequence that starts with toolsets, adds explicitly enabled tools, and removes explicitly disabled tools. For the full flowcharts and worked examples, see [Tools resolution](./tools-resolution.md).
